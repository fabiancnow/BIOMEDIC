# Supabase Postgres Best Practices — BIOMEDIC

## Reglas de Base de Datos y Seguridad (`public.leads`)

1. **Estructura Obligatoria de la Tabla `public.leads`:**
   - `id`: `bigint generated by default as identity primary key`
   - `created_at`: `timestamptz not null default now()`
   - `nombre_completo`: `text not null`
   - `correo_electronico`: `text not null`
   - `whatsapp`: `text not null`
   - `empresa_negocio`: `text not null`
   - `presupuesto_estimado`: `text not null`
   - `dolor_principal`: `text not null`
2. **Row Level Security (RLS):**
   - Habilitar siempre RLS en `public.leads`.
   - Definir política `FOR INSERT TO anon, authenticated WITH CHECK (true)` para que la Landing Page pública pueda registrar prospectos y citas desde móvil y escritorio.
3. **Manejo Seguro de Variables de Entorno:**
   - Usar únicamente `NEXT_PUBLIC_SUPABASE_URL` y `NEXT_PUBLIC_SUPABASE_ANON_KEY` en el cliente web; nunca exponer la llave `service_role`.
